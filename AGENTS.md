# Public snapshot rules

- Never add credentials, production domains, databases, private screenshots, personal health values, or private reader names.
- Keep Android AGPL-3.0 and server MIT license/provenance files intact.
- Public examples use `health.example.com` and synthetic data only.
- Health access stays read-only; screen-time permission stays optional.
- Release APKs must match tagged source and include SHA-256 and signing certificate fingerprint.
