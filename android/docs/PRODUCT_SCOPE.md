# ReadMe Android product scope

ReadMe has three user-facing responsibilities:

1. show a compact local view of supported Health Connect records;
2. upload user-approved records to the configured self-hosted server;
3. show which named MCP reader queried which categories and time range.

Health records are read-only. Usage Access is optional and limited to foreground-duration totals. Reader names come from server credentials and are not hard-coded. Direct Bluetooth pairing, vendor-account extraction, band resets, and health-record modification are outside the supported product scope.
